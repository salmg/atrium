ISO 8583 — Host Layer

          
The link above the card: acquirer ⇄ gateway ⇄ issuer. Meets the card side at DE55.

        

        

          
        

      


      

        

        

          No link
          Start a proxy to observe or rewrite a host link
        

      


      

        
        
        
        
      


      
      

        

          

            

              
Proxy

              

                Passive observes and changes nothing. Mutating rewrites live messages per a
                playbook and asks for confirmation first.
              

            

            

              
              
            

          


          

            

              
              
            

            

              
              
            

            

              
              
            

            

              
              
            

            

              
              
            

            

              
              
            

            

              
              
            

            

              
            

          


          

            The mutating proxy re-encodes the messages a rule matches, so a wrong dialect
            costs a transaction rather than a capture. Everything else is forwarded byte for byte.
          

          

        


        

          

            

              
Live

              
Messages as they cross, newest last
